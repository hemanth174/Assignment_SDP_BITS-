GIT COMMANDS — ASSIGNMENT_SDP_BITS-

Repository:
https://github.com/hemanth174/Assignment_SDP_BITS-.git

The GitHub repository and feature PR have already been created. Use these commands in PowerShell to work with the same repository locally.

A. Get the project locally

1. git clone https://github.com/hemanth174/Assignment_SDP_BITS-.git
   Downloads the GitHub repository and its commit history to your computer.

2. cd Assignment_SDP_BITS-
   Moves into the cloned project folder.

3. git status
   Shows the current branch and whether the working tree has changes.

4. git log --oneline --graph --decorate --all
   Displays the available commits and branch history.

B. Make and commit a main-branch update

5. git switch main
   Switches to the main branch.

6. notepad index.html
   Opens the home page so you can make a small visible text change and save it.

7. git add index.html
   Stages the modified home page.

8. git commit -m "Update GameVault home page"
   Records the home-page update as a new commit.

C. Get the feature branch and inspect it

9. git fetch origin
   Downloads the latest branch and commit information from GitHub.

10. git switch --track origin/feature/about-page
    Creates a local tracking branch for the feature branch already published on GitHub.

11. git log --oneline --graph --decorate --all
    Confirms the feature branch and its commits are visible in the local history.

D. Merge the feature locally (alternative to merging the PR)

12. git switch main
    Returns to the main branch before merging.

13. git merge --no-ff feature/about-page -m "Merge about page feature"
    Merges the feature branch and creates a visible merge commit.

14. git log --oneline --graph --decorate --all
    Shows the merge commit and branch history.

15. git push origin main
    Publishes the local main-branch commits to GitHub.

Note: If you merge Pull Request #1 on GitHub instead, do not also perform step 13. After merging the PR, run:
    git switch main
    git pull origin main

E. Verify .gitignore

16. notepad .gitignore
    Opens the ignore file. It should contain *.log and /temp/.

17. New-Item -ItemType File -Name "check.log"
    Creates a sample log file in PowerShell.

18. New-Item -ItemType Directory -Name "temp"
    Creates the temporary directory listed in .gitignore.

19. git status --short
    Checks that check.log and files inside temp are not shown as untracked files.

F. Demonstrate undoing a commit safely

20. Set-Content -Path "revert-demo.txt" -Value "Temporary commit for revert demonstration"
    Creates a small file for the undo demonstration.

21. git add revert-demo.txt
    Stages the demonstration file.

22. git commit -m "Add temporary revert demonstration file"
    Creates the extra commit that will be undone.

23. git revert --no-edit HEAD
    Creates a new commit that reverses the previous commit without deleting history.

24. git log --oneline -5
    Confirms that both the original commit and the revert commit remain in history.

G. Push your work

25. git push -u origin main
    Pushes the main branch and configures its upstream branch.

26. git push -u origin feature/about-page
    Pushes the feature branch and configures its upstream branch.

27. git push
    Pushes later commits to the configured upstream branch.

H. Pull Request workflow

28. Open https://github.com/hemanth174/Assignment_SDP_BITS-/pull/1
    Opens Pull Request #1, which proposes merging feature/about-page into main.

29. Review the changed files and PR description on GitHub.
    Checks the feature changes before merging.

30. Click "Merge pull request" on GitHub only after reviewing the PR.
    Completes the reviewed feature merge and records the merge on GitHub.

31. git switch main
    Returns to the local main branch after the PR is merged.

32. git pull origin main
    Downloads the merged main-branch history to your computer.
